# ЭлектроМир
## Технологии
Python, Tkinter, SQLite, Pillow

## Функции
Каталог товаров (поиск, фильтр)
Оформление заказа (корзина, расчёт)
Управление заказами (статусы, история)

## Роли
Клиент — каталог, заказы
Менеджер — товары, все заказы
Администратор — пользователи, роли

## База данных
Файл: db/db_variant_1.db`

Таблицы: `users`, `products`, `orders`, `order_items`

## Запуск
pip install -r requirements.txt
python main.py
